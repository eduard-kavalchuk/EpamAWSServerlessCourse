1. Grant full access to the Amazon S3 service for the ${iam_role} role. Please use an existing AWS policy; do not create your own.

aws iam attach-role-policy \
    --role-name ${iam_role} \
    --policy-arn arn:aws:iam::aws:policy/AmazonS3FullAccess

aws iam attach-role-policy \
    --role-name cmtr-mxhmo8sx-iam-peld-iam_role \
    --policy-arn arn:aws:iam::aws:policy/AmazonS3FullAccess

2. Update the resource-based S3 bucket policy to prohibit the deletion of any objects inside the ${s3_bucket} bucket specifically for the ${iam_role} role.


YOUR_ACCOUNT_ID is a 12-digit number (no hyphens!) that can be found in the upper right corner of Management Console.
iam_role in this task is cmtr-mxhmo8sx-iam-peld-iam_role

# ----- [policy.json] ---------------------
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Deny",
            "Principal": {
                "AWS": "arn:aws:iam::YOUR_ACCOUNT_ID:role/${iam_role}"
            },
            "Action": [
                "s3:DeleteObject",
                "s3:DeleteObjectVersion"
            ],
            "Resource": "arn:aws:s3:::${s3_bucket}/*"
        }
    ]
}


# Be aware to put file:// in front of *relative* path to policy.json!

aws s3api put-bucket-policy \
    --bucket ${s3_bucket} \
    --policy file://policy.json

aws s3api put-bucket-policy \
    --bucket cmtr-mxhmo8sx-iam-peld-bucket-7269810 \
    --policy file://policy.json
